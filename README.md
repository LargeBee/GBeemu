# GBeemu
Cycle accurate GameBoy emulator built in C++ with Visual Studio

### Current Features
Pause/Reset\
Skip Boot Sequence\
Scale screen 1-5x\
Trace Viewer\
Stats Viewer

### Planned Features (eventually)
Saving and loading states\
Palette Editing\
Key Rebinding\
Memory Viewer\
Tile Viewer\
Making better window layouts so you can view hardware information without it blocking the game area\
Making the audio more accurate to hardware
